# Cadence: Random Topic Generator & Speech Practice

![Cadence Hero](public/favicon.svg) <!-- Replace with an actual screenshot when deployed -->

**Cadence** is a modern, web-based tool designed to help individuals overcome public speaking anxiety and improve their impromptu speaking skills. By providing a random topic, enforcing a strict 60-second time limit, and utilizing AI-driven feedback, Cadence acts as your personal speech coach.

## 🚀 Features

- **Random Topic Generation:** Pulls from a curated list of topics across various categories (e.g., Philosophy, Science, Everyday Life) and difficulty levels.
- **Time Pressure Simulation:** A strict 60-second countdown timer helps eliminate filler words and teaches you to get straight to the point.
- **Audio & Video Recording:** Practice using just your voice, or enable video to review your body language and eye contact.
- **AI Speech Analysis:** Get instant, personalized feedback on your speech's structure, vocabulary, and delivery, along with a performance score out of 100.
- **SEO Optimized:** Fully optimized for search engines with semantic HTML, rich meta tags, Open Graph data, and on-page FAQ content.
- **Premium Aesthetics:** Built with a beautiful, dark-mode first design system utilizing the Google "Outfit" font.

## 🛠️ Tech Stack

- **Framework:** [React 18](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Custom CSS Variables (Design Tokens)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Media:** HTML5 MediaRecorder API (Audio/Video capturing)

## 🏃‍♂️ Getting Started Locally

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/cadence.git
   cd cadence
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:5173`

## 🌍 Deployment

This app is designed to be easily deployed on platforms like **Vercel** or **Netlify** for free hosting and excellent SEO performance.

### Deploying to Vercel (Recommended):
1. Create a free account on [Vercel](https://vercel.com/).
2. Connect your GitHub account and import this repository.
3. Configure the framework preset to **Vite**.
4. Click **Deploy**. Your app will be live and secured with HTTPS instantly!
